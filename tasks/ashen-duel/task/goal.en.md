# Ashen Duel

Build **Ashen Duel**, a polished browser-native 3D third-person boss fight with Three.js, inspired by the readable combat rhythm of **Elden Ring** without copying its protected assets. Create an original ruined arena, a stamina-based player with lock-on attacks, dodging and healing, and one challenging guardian whose clearly telegraphed moves evolve across multiple phases; the player should win by learning the fight rather than button-mashing, with responsive desktop and mobile controls and a clear restart flow. Minimum delivery bar: leave a working game, not an unfinished scaffold. Before stopping, run `npm run build`, fix every build error, confirm that `dist/` is emitted, and make sure the real game is connected to the page entry point. If time is tight, reduce optional scope or polish rather than leave the game unable to build or start.
