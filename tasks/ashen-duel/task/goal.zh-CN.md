# Ashen Duel / 灰烬决斗

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 第三人称 Boss 战游戏 **Ashen Duel**，借鉴 **《艾尔登法环》**清晰可读的战斗节奏，但不复制其受保护资产。设计原创的破败竞技场、具有锁定攻击、体力、翻滚和治疗能力的玩家角色，以及一名招式预兆明确、会在多个阶段改变打法的守护者；玩家应当靠观察和学习赢得战斗，而不是无脑连按，同时支持响应迅速的桌面与手机操作以及清晰的重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
