# Turbo Circuit

Build **Turbo Circuit**, a polished browser-native 3D arcade kart racer with Three.js, inspired by the colorful circuits, drift boosts, items and rival racing of **Mario Kart** without copying its protected assets. Create an original looping track where the player races several AI opponents over multiple laps, earns speed through well-timed drifts, uses offensive and defensive items, discovers alternate lines and fights for first place, with lively feedback, responsive desktop and mobile controls, and a clear finish and restart flow. Minimum delivery bar: leave a working game, not an unfinished scaffold. Before stopping, run `npm run build`, fix every build error, confirm that `dist/` is emitted, and make sure the real game is connected to the page entry point. If time is tight, reduce optional scope or polish rather than leave the game unable to build or start.
