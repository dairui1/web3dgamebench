# Turbo Circuit / 涡轮巡回赛

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 街机卡丁车游戏 **Turbo Circuit**，借鉴 **《马力欧赛车》**的彩色环形赛道、漂移加速、道具和对手竞速，但不复制其受保护资产。设计一条原创闭环赛道，让玩家与多名 AI 对手进行多圈比赛，通过恰当漂移获得加速，使用攻防道具，探索替代路线并争夺第一名；游戏应有活泼有力的反馈、响应迅速的桌面与手机操作，以及明确的冲线和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
