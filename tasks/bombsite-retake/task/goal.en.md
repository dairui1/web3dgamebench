# Bombsite Retake

Build **Bombsite Retake**, a polished browser-native 3D tactical first-person shooter with Three.js, inspired by the bomb-retake tension of **Counter-Strike 2** without copying its protected assets. Put the player in an original compact industrial site where a device is already planted and defended by enemy bots: they must choose a route, survive a readable firefight, secure the site and manually defuse before time runs out, with satisfying weapons, useful tactical choices, responsive desktop and mobile controls, and a clear win, loss and restart flow. Minimum: `npm run build` must succeed and emit a playable `dist/`.
