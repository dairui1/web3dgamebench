# Bombsite Retake / 爆破点夺回

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 战术第一人称射击游戏 **Bombsite Retake**，借鉴 **《Counter-Strike 2》**爆破点夺回的紧张感，但不复制其受保护资产。让玩家进入一处原创的紧凑工业设施，面对已经安放的装置和负责防守的敌方 Bot：玩家要选择路线，在清晰可读的交火中存活，控制现场并在倒计时结束前亲手完成拆除；游戏应有令人满意的武器反馈、有意义的战术选择、响应迅速的桌面与手机操作，以及明确的胜负和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
