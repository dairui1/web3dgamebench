# Village Quest / 村庄任务

## 目标

使用 Three.js 制作一款完整、精致、原生运行于浏览器的 3D 第三人称任务 RPG **Village Quest**。它以 **《魔兽世界》**广为人知的 NPC 接取任务、目标战斗、拾取战利品、任务追踪与交付循环作为共同玩法参照。这是一个紧凑的单人垂直切片，不是联网 MMO。名称、角色、生物、地点、故事、图标、音频和界面资产都必须原创。

玩家抵达一座小村庄，与守望者交谈并接受任务，前往附近遗迹，击败三只腐化生物，拾取掉落的遗物，再返回守望者领取奖励。只有明确完成任务交付才算胜利，单纯击败敌人不能通关。

## 运行完成合同

实现下述游戏。`npm run build` 成功并生成 `dist/` 后，Goal 即完成。

不要编写或运行浏览器自动化、自动化运行检查、自动驾驶器或完整通关流程。运行表现、响应式适配、功能完整度、平衡、打磨和游戏手感由提交后的评测检查。只报告实际执行过的构建。

## 目标游戏系统

- 带碰撞的第三人称移动、环绕跟随相机、清晰角色朝向，以及点击、触摸或按键交互。
- 一名友方任务 NPC，具有接近提示、对话面板、接受操作、进行中对话和完成领奖对话。
- 最近目标或明确选定目标，配合可见目标框和距离反馈。
- 基础攻击和两个技能：一个有冷却的伤害技能，以及一个消耗资源且有冷却的治疗或防御技能。
- 遗迹附近的三只敌对生物至少分属两种行为角色，其中包括追击者，以及会以清晰前摇发动远程或范围攻击的敌人。它们具有警戒范围、攻击、受击和死亡状态，并在满足击杀要求后确定性掉落一件遗物。
- 至少一种有前摇的敌方攻击必须让治疗或防御技能具有实际价值；技能的冷却与资源消耗要形成真实的时机选择，而不是装饰按钮。
- 任务追踪阶段：`available`、`accepted`、`creatures-defeated`、`relic-collected`、`ready-to-turn-in` 和 `complete`。
- 生命值、技能资源、冷却、目标生命、目标计数、战利品拾取、奖励展示、胜利、失败和重开。
- 桌面键盘与指针控制，以及可用的手机移动、相机、选定、交互、攻击和技能控制。
- 最低输入约定：桌面端向前移动必须响应 W 或上方向键之一；手机端主要移动区必须位于屏幕左下控制区域。

## 执行检查点

1. 建立村庄、路线、遗迹、玩家移动、相机、碰撞与响应式输入。
2. 完成 NPC 对话和从可接受到已接受的任务状态机。
3. 完成选定目标、技能、敌人、战斗反馈、死亡、遗物掉落和拾取。
4. 完成返回交付、奖励、UI、失败与重开、环境打磨和清晰地标。
5. 最后一次相关修改后执行一次 `npm run build`。成功生成 `dist/` 后立即结束，运行表现由提交后的评测检查。

## 质量目标

- 任务追踪器和世界提示必须对当前行动保持一致。
- 敌人不能穿过实体墙体攻击，也不能在死亡后继续造成伤害。
- 两种敌人角色在行为上必须清楚可辨，高威胁攻击也要给治疗或防御技能留下公平、可观察的响应窗口。
- 遗物不能在满足掉落条件前拾取，玩家不返回守望者就不能完成任务。
- 对话、目标框、技能控制和世界在手机上不能互相遮挡，且都可使用。
- 页面不可见时应安全暂停战斗与冷却推进。

- 在 1440 x 900 和 390 x 844 下，页面横向溢出不得超过 2 个 CSS 像素，运行时不得产生未捕获页面异常或 `console.error` 输出。

该对象从首个渲染帧起就必须字段完整并通过 schema，开始前反映可玩的初始状态；重新开始后，除 `restartCount` 外必须回到同一状态。游玩中按 `R` 必须立即重新开始，手机模式必须提供文本、`aria-label` 或 title 明确写有“重开”或“Restart”的可见控件；任一路径都只让 `restartCount` 增加一次。

- `phase`：`ready`、`playing`、`paused`、`won` 或 `lost`；
- `score`：有限数值；
- `player`：由有限数值组成的 `{ x, y, z }`；
- `health`：0 到 100 的有限数值；
- `resource`：非负有限数值；
- `questStage`：`available`、`accepted`、`creatures-defeated`、`relic-collected`、`ready-to-turn-in` 或 `complete`；
- `enemiesDefeated`：0 到 3 的整数；
- `enemyRolesDefeated`：非负整数，记录已击败敌人所覆盖的不同战斗行为类型数量；
- `defensiveAbilityUses`：非负整数，只统计实际恢复缺失生命或减免伤害的有效治疗/防御技能；
- `relicCollected`：布尔值；
- `targetId`：字符串或 `null`；
- `seed`：`46349`；
- `restartCount`：非负整数。

可以增加字段，但不得暴露只供评测器使用的捷径或可调用函数。
