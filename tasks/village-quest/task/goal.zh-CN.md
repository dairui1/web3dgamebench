# Village Quest / 村庄任务

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 第三人称任务 RPG **Village Quest**，借鉴 **《魔兽世界》**的 NPC 任务、目标战斗、战利品和交付循环，但不复制其受保护资产。设计一座原创的紧凑村庄和附近遗迹，让玩家从守望者处接受任务，运用多种实用技能与行为不同的腐化生物战斗，找回遗物并返回领取奖励；游戏应有清晰的对话和目标反馈、响应迅速的桌面与手机操作，以及明确的胜负和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
