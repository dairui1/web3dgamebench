# Village Quest

Build **Village Quest**, a polished browser-native 3D third-person quest RPG with Three.js, inspired by the NPC quest, target combat, loot and turn-in loop of **World of Warcraft** without copying its protected assets. Create an original compact village and nearby ruin where the player accepts a quest from a warden, fights distinct corrupted creatures with several useful abilities, recovers a relic and returns it for a reward, with clear dialogue and objective feedback, responsive desktop and mobile controls, and a clear win, loss and restart flow. Minimum delivery bar: leave a working game, not an unfinished scaffold. Before stopping, run `npm run build`, fix every build error, confirm that `dist/` is emitted, and make sure the real game is connected to the page entry point. If time is tight, reduce optional scope or polish rather than leave the game unable to build or start.
