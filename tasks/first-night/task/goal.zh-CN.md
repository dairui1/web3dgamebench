# First Night / 初夜生存

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 体素生存游戏 **First Night**，借鉴 **《我的世界》**的探索、方块破坏与放置、制作和夜间生存体验，但不复制其受保护资产。生成一座原创的紧凑岛屿，让玩家收集木材与石材、制作信标、搭建真正封闭的庇护所、把信标放到屋顶，并在敌对生物的威胁下存活到黎明；游戏应有令人满意的世界交互、响应迅速的桌面与手机操作，以及明确的胜负和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
