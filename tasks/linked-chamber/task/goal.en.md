# Linked Chamber

Build **Linked Chamber**, a polished browser-native 3D first-person spatial puzzle with Three.js, inspired by the paired-portal traversal and momentum puzzles of **Portal 2** without copying its protected assets. Create one original test chamber where the player places a linked portal pair on suitable surfaces, redirects their movement, carries a cube through the portals, uses it to hold a floor switch and reaches the locked exit, with readable spatial cues, responsive desktop and mobile controls, and a clear completion and restart flow. Minimum delivery bar: leave a working game, not an unfinished scaffold. Before stopping, run `npm run build`, fix every build error, confirm that `dist/` is emitted, and make sure the real game is connected to the page entry point. If time is tight, reduce optional scope or polish rather than leave the game unable to build or start.
