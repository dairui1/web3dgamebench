# Linked Chamber / 联结密室

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 第一人称空间解谜游戏 **Linked Chamber**，借鉴 **《Portal 2》**的成对传送门穿越和动量谜题，但不复制其受保护资产。设计一间原创测试密室，让玩家在合适表面放置一对联结传送门、重定向自己的移动、把方块带过传送门、用它压住地面开关并抵达锁定出口；游戏应有清晰的空间提示、响应迅速的桌面与手机操作，以及明确的完成和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
