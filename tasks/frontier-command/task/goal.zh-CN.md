# Frontier Command / 边境指挥

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 即时战略游戏 **Frontier Command**，借鉴 **《魔兽争霸 III》**的资源采集、基地建造、部队生产和战场指挥循环，但不复制其受保护资产。在一张原创的紧凑战场上，让玩家指挥工人采集木材与矿石、扩建小型基地、训练军队、抵挡敌方突袭并摧毁对方据点；游戏应有清晰的选择与命令反馈、可用的桌面与手机操作，以及明确的胜负和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
