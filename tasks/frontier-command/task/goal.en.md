# Frontier Command

Build **Frontier Command**, a polished browser-native 3D real-time strategy game with Three.js, inspired by the gathering, base-building, unit production and battlefield command loop of **Warcraft III** without copying its protected assets. On an original compact battlefield, let the player command workers, gather wood and ore, expand a small base, train an army, survive an enemy raid and destroy the opposing stronghold, with clear selection and command feedback, usable desktop and mobile controls, and a clear win, loss and restart flow. Minimum delivery bar: leave a working game, not an unfinished scaffold. Before stopping, run `npm run build`, fix every build error, confirm that `dist/` is emitted, and make sure the real game is connected to the page entry point. If time is tight, reduce optional scope or polish rather than leave the game unable to build or start.
