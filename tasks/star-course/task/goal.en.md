# Star Course

Build **Star Course**, a polished browser-native 3D platform game with Three.js, inspired by the free-running movement, follow camera, collectibles, enemies and goal-star structure of **Super Mario 64** without copying its protected assets. Create an original compact course that carries the player from a grassy opening across a moving-platform ravine to a summit, rewarding coin collection, skillful enemy interaction and confident traversal before the final star, with expressive movement, responsive desktop and mobile controls, and a clear win, loss and restart flow. Minimum delivery bar: leave a working game, not an unfinished scaffold. Before stopping, run `npm run build`, fix every build error, confirm that `dist/` is emitted, and make sure the real game is connected to the page entry point. If time is tight, reduce optional scope or polish rather than leave the game unable to build or start.
