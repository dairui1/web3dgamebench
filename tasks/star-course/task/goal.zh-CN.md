# Star Course / 星光之路

使用 Three.js 制作一款精致、原生运行于浏览器的 3D 平台游戏 **Star Course**，借鉴 **《超级马力欧 64》**的自由奔跑、跟随相机、收集物、敌人和目标星星结构，但不复制其受保护资产。设计一条原创的紧凑路线，让玩家从草地起点出发，跨越移动平台峡谷并抵达山顶，在取得最终星星前通过金币收集、技巧型敌人互动和稳定的平台穿越获得回报；游戏应有富有表现力的移动、响应迅速的桌面与手机操作，以及明确的胜负和重开流程。 最低交付要求：必须留下能正常运行的游戏，而不是未完成的脚手架。结束前务必执行 `npm run build`，修完所有构建错误，确认生成 `dist/`，并确保真正的游戏代码已经接入页面入口。如果时间紧张，应缩减非必要范围或打磨工作，不能留下无法构建或无法启动的版本。
